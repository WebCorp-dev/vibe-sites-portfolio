# Портфолио демо-сайтов · WebCorp

Три живых демо-сайта для барбершопа, салона красоты и кофейни. Каждый — со своей структурой, анимациями и сценарием заявки. Ни одного шаблона «отзывы — мастера — контакты».

👉 **Открыть портфолио:** https://webcorp-dev.github.io/vibe-sites-portfolio/

## Что здесь видно

- **Motion-дизайн:** плавающие фото и шары, появление блоков при скролле, hover-анимации, 3D-преобразования.
- **Интерактив:** выбор услуги sphere/колесом, фильтры отзывов, вкладки меню, счётчик количества, калькуляция заказа.
- **Стеклянные кнопки** в стиле iOS: полупрозрачная подложка, `backdrop-filter: blur`, цветная рамка и мягкая тень.
- **Реальные заявки:** формы всех трёх сайтов отправляют сообщения в Telegram-бота `@webcorp_zayavki_bot`.
- **Адаптивность:** все страницы работают на телефоне и на десктопе.
- **Фото лежат в репозитории** (`assets/img/`) — сайты не зависят от внешних хостингов картинок.

## Технологии

Сейчас: **HTML + CSS + JavaScript** (без сборки и зависимостей).
Следующий этап: **React + Tailwind + Vite**.

## Как запустить локально

Вариант 1 — PowerShell-скрипт из корня проекта:

```powershell
.\serve.ps1
```

Вариант 2 — Python:

```bash
python -m http.server 8000
```

После этого открыть http://localhost:8000/
